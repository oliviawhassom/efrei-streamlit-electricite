1. Introduction

1.1 The question

France wants more renewable electricity, but a national average hides big differences between regions. Some have a lot of nuclear plants, some have dams, some have wind, and some produce very little. I wanted to know three things:

  1. Is the renewable share of production really going up?
  2. Which regions are ahead and which ones are behind?
  3. What happens to the share if each source keeps growing at a given speed?

The audience is students, citizens and regional decision makers who want to compare their region with the others.

1.2 Dataset

The data is Production regionale mensuelle d'electricite par filiere, published by RTE through Open Data Reseaux Energies (ODRE) on data.gouv.fr, under the Licence Ouverte 2.0.

Link: https://www.data.gouv.fr/datasets/production-regionale-mensuelle-delectricite-par-filiere

Column Meaning
mois The month (one row per region and per month)
code_insee_region / region Administrative region
production_nucleaire Nuclear production (GWh)
production_thermique Thermal production: gas, coal, oil (GWh)
production_hydraulique Hydro production (GWh)
production_eolienne Wind production (GWh)
production_solaire Solar production (GWh)
production_bioenergies Bioenergies production (GWh)

I grouped hydro, wind, solar and bioenergies as renewable. Production is not consumption: imports and exports between regions are not in this file.

4. Feature engineering

New variables:

  • year and month_num, for trends and seasons
  • group: Renewable (hydro, wind, solar, bioenergies), Nuclear, Thermal
  • the share of each group in the production of a region (or of the whole selection)
long = wide_clean.melt(id_vars=["month", "code", "region"], value_vars=sources, var_name="source", value_name="gwh")
long["year"] = long["month"].dt.year
long["month_num"] = long["month"].dt.month

def to_group(s):
    if s in RENEWABLE:
        return "Renewable"
    if s in FOSSIL:
        return "Thermal (gas, coal, oil)"
    return s

long["group"] = long["source"].map(to_group)

def add_shares(d, by):
    tot = d.groupby(by + ["group"], as_index=False)["gwh"].sum()
    w = tot.pivot_table(index=by, columns="group", values="gwh", fill_value=0).reset_index()
    for g in ["Renewable", "Nuclear", "Thermal (gas, coal, oil)"]:
        if g not in w.columns:
            w[g] = 0.0
    w["total"] = w[["Renewable", "Nuclear", "Thermal (gas, coal, oil)"]].sum(axis=1)
    w["renew_share"] = 100 * w["Renewable"] / w["total"].replace(0, np.nan)
    w["nuclear_share"] = 100 * w["Nuclear"] / w["total"].replace(0, np.nan)
    w["thermal_share"] = 100 * w["Thermal (gas, coal, oil)"] / w["total"].replace(0, np.nan)
    return w

Question: If each source kept growing at a constant yearly rate, where would the renewable share be in a few years?

The rates below are my own rough assumptions, only there to play with. This is not a forecast.

growth = {            # % per year, change them and run the cell again
    "Solar": 10.0,
    "Wind": 6.0,
    "Hydro": 0.0,
    "Bioenergies": 2.0,
    "Nuclear": 0.0,
    "Thermal (gas, coal, oil)": -3.0,
}
last_year = int(ld["year"].max())
target = last_year + 9

base = ld[ld["year"] == last_year].groupby("source")["gwh"].sum()
rows = []
for y in range(last_year, target + 1):
    k = y - last_year
    vals = {s: base[s] * (1 + growth.get(s, 0) / 100) ** k for s in base.index}
    total = sum(vals.values())
    ren = sum(v for s, v in vals.items() if s in RENEWABLE)
    rows.append((y, 100 * ren / total))
proj = pd.DataFrame(rows, columns=["year", "renew_share"])

fig, ax = plt.subplots(figsize=(9, 4.5))

2025: 28.4 %   ->   2034: 37.9 %

def final_share(g):
    k = target - last_year
    vals = {s: base[s] * (1 + g.get(s, 0) / 100) ** k for s in base.index}
    return 100 * sum(v for s, v in vals.items() if s in RENEWABLE) / sum(vals.values())

ref = final_share(growth)
sens = {}
for s in base.index:
    g2 = dict(growth)
    g2[s] = g2.get(s, 0) + 2
    sens[s] = final_share(g2) - ref
sens = pd.Series(sens).sort_values(key=abs, ascending=False)
say(f"**Observation:** With my assumptions the renewable share goes from {proj.iloc[0]['renew_share']:.1f} % in {last_year} to {ref:.1f} % in {target}. "
    f"Adding 2 points to the yearly growth of one source, the biggest effect on the {target} share comes from **{sens.index[0]}** ({sens.iloc[0]:+.1f} points).")
say("**Interpretation:** The result depends mostly on the sources that are big at the start or that grow fast. "
    "It is a way to see which assumption matters, not a prediction, because nothing here links the production with the consumption or the grid.")

Implications and next steps

  • Add consumption data to see which regions import electricity.
  • Add installed capacity to compare production with what could be produced.
  • Use real region borders (geojson) for a proper map.
  • Add CO2 emissions per source.

Limits

  • Production is not consumption, imports and exports between regions are not included.
  • Hydro includes pumped storage, thermal mixes gas, coal and oil.
  • The publisher updates the dataset and can revise past values, so a newer download can differ a little from mine.
  • The last year is usually incomplete, so I kept full years only.
  • The what-if uses my own assumptions and no link with consumption, prices or policy.
  • The map uses approximate region centers.
  • The data is aggregated by region and month, so there is no personal data.
  • A chart shows how the mix changed, it does not prove why.
